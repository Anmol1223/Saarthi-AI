# Development Principles

1. Build Phase I completely before Phase II.

2. Build Phase II completely before Phase III.

3. Do not build advanced features before foundation modules are stable.

4. Automate repetitive operations whenever possible.

5. Prefer free/open-source solutions before paid services.

6. AI should enhance the product, not become a dependency.

# Automated Project Status Rules

## Rule 1: Mandatory Status Update

After every completed task:

1. Update PROJECT_STATUS.md
2. Update Sprint Progress
3. Update Development Log
4. Commit Changes

Example:

Completed:
- Notes Search
- Login Page

Commit:
git commit -m "feat: add notes search"

## Rule 2: Sprint Management

Each sprint must contain:

- Goal
- Tasks
- Progress Percentage
- Status

Possible Status:

- Planned
- In Progress

- Completed
- Blocked
