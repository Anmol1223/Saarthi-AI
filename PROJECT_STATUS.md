# Development Principles

1. Build Phase I completely before Phase II.

2. Build Phase II completely before Phase III.

3. Do not build advanced features before foundation modules are stable.

4. Automate repetitive operations whenever possible.

5. Prefer free/open-source solutions before paid services.

6. AI should enhance the product, not become a dependency.
